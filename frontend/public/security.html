VantaCore / Security and privacy

Is VantaCore safe?

Yes. The free VantaCore web demo at vantacore.net compresses your text entirely inside your browser. Your text is not uploaded to a VantaCore server, there is no signup or login, and the full source code is public on GitHub so anyone can check.

VantaCore turns long AI chats, dev logs, research notes, and knowledge-base material into compact, LLM-ready “memory capsules.” In the site’s demo benchmark, a 1,607,470-character multi-session AI export became a 61,109-character capsule, a 96.2% reduction. Results depend on your input. VantaCore is not connected to the ransomware group or the other companies that share its name (see below).

What happens to your text

  • It stays on your device. When you paste text or add a file (.txt, .md, .json, .csv, .log), your browser reads it locally. Adding a file opens it in your browser. It is not sent to us.
  • Compression runs in your browser. The compression engine is part of the page’s own JavaScript. The free demo has no backend compression server.
  • No account. There is no signup, login, or payment for the free demo.
  • Exports are saved straight to your device. TXT, MD, and JSON exports go from your browser to your device.
  • Your content stays yours. VantaCore does not claim ownership of your input or output. Free exports include a short attribution line naming VantaCore as the generator of the capsule format.

What else the page loads: Like most websites, vantacore.net loads Google Analytics for basic visit statistics and Google Fonts for its typefaces. VantaCore’s code does not send your text to these services or to anyone else.

How to check this yourself

  1. Watch the network. Open vantacore.net, open your browser’s developer tools (F12, or Cmd+Option+I on Mac), and go to the Network tab. Clear the list, paste some text, and click Compress. No request will contain your text.
  2. Go offline. After the page loads, turn off Wi-Fi or set the Network tab to Offline, then compress. It still works, because the engine is already loaded in the page.
  3. Read the code. The source is at github.com/DVRK-ORG/VantaCore. The engine (frontend/src/engine/singularity.ts) contains no network code, and the app has no code that sends your text anywhere.
  4. Run it yourself. Clone the repo, run npm install and npm run dev in the frontend folder, and use it at localhost:5173. When we checked on 2026-10-26, building commit 7a120e9 with npm run build produced a JavaScript file byte-for-byte identical to the one served at vantacore.net.

What we store

Everything below is stored only in your browser, on your device:

  • Your last 20 compressions (compressed output, file name, and stats), so you can reopen them from History.
  • A daily counter for the free demo’s 5 local compressions per day.
  • Your export folder choice, if you pick one in a browser that supports it.

The free demo has no VantaCore account, cloud sync, or server-side storage for your content.

To clear it: open History in the top bar and click Clear History, or delete single entries there. To remove everything, clear site data for vantacore.net in your browser settings. In a private or incognito window, it is all discarded when you close the window.

What Pro will change

VantaCore Pro is not available yet. The site says it is being shaped for developers and AI power users who need batch compression, CLI workflows, MCP tools, advanced exports, and project memory capsules:

  • CLI: local file compression, validation, stats, and developer automation.
  • MCP: agent tools for compressing files, creating capsules, and preparing RAG inputs.
  • Pro Web: batch workflows, advanced exports, profiles, and deeper local history.

The free web demo stays local-first. Pro adds scale and automation without putting the free demo behind an account wall.

FAQ

Does VantaCore upload my data?

No. The free VantaCore web demo processes your text in your browser. Your text is not sent to a VantaCore server, and no account is needed.

Is VantaCore the ransomware group?

No. VantaCore at vantacore.net is a client-side tool that compresses AI chats and logs into memory capsules. It is not affiliated with the ransomware group that uses the same name, or with VantaCore AI Inc.

Do I need an account to use VantaCore?

No. The free web demo has no signup and no login. It includes 5 local compressions per day.

Is VantaCore open source?

Yes. The source code is public at github.com/DVRK-ORG/VantaCore under the MIT License, so anyone can read it, run it locally, or check how it works.

Where does VantaCore store my history?

Only in your browser's local storage on your device. It keeps your last 20 compressions. You can delete them anytime with Clear History.

Does VantaCore own my content?

No. VantaCore does not claim ownership of your input or output. Free exports include a short VantaCore attribution line for the capsule format.
